# 验证记录

3D 版本验证日期：2026-09-19；2026-09-24 继续完成回归。以下区分实际运行的测试与仍需真机验证的目标。

## 自动化逻辑测试

`npm run check` 和 `npm test` 通过，125 项测试：

- 18 项相机拾取测试：两种视角 × 四种尺寸，全部 126 个网格以及有高度的反弹器顶面投影；额外覆盖越界、空视口、切换和缩放。
- 51 项物理测试：不同速度 / 入射角 / 反弹角、端点、切线、重合圆、分离接触、四面墙和角落、高速薄反弹器穿透、重力积分、能量稳定。
- 空棋盘 60 秒重力与碰撞模拟的最大机械能漂移为 **0.526%**，低于 5% 目标。此处机械能包含重力势能，不能只比较球速。
- 库存守恒、无效放置、旋转和回收；电击连锁、冰冻、重型击退、分裂限制和炸弹禁用恢复。
- 暂停、6 秒自动选牌、前四波保底、BOSS 前重抽、怪物引入顺序。
- BOSS 三机制及阶段切换、胜负结算、本地存储损坏 / 不可用、星币消费和重开清空。
- 连击状态机：2.0 秒窗口内累加与重置、阈值 5/10/15 升级、×4 封顶、电击连锁逐杀累加、倍率真实乘进命中分与击杀分、BOSS 分数不乘倍率、非击杀命中不动连击、暂停冻结窗口、跨波 / 跨 BOSS 阶段静默清零且不发 comboBreak / comboTier 事件、超时只发一次 comboBreak。
- 无漏波奖励：波次阶段漏怪置位 waveHadLeak、BOSS 脉冲与潮群怪触底不置位、beginWave 跨波复位、整波聚合判定结算时加分 50+wave*50 并发 perfectWave 事件、任一漏怪取消奖励、reward 推进不重复触发、胜负分支不越过结算、本局失败时不分发奖励。
- 8 个固定种子，使用可重复的基础布局、电击 / 分裂优先卡牌选择，全部完成 12 波及三阶段 BOSS。含接近完整选牌等待的单局用时为 **293–321 秒**。这验证可通关与节奏，并不表示任何布局都能获胜。

## 运行性能与限制

2026-09-24，Chrome 154、1440×1000、原生 GPU WebGL（Intel Iris Plus Graphics 655 / ANGLE Metal）。密集场景初始装载 18 颗弹球、18 块反弹器和 24 只怪物，5 秒样本约 **59.1fps**。CDP `TaskDuration` 占墙钟时间约 **22.9%**；这是单页主线程忙碌比例，**不是整机 CPU 使用率**。场景在采样时继续模拟，实体数量会因战斗变化，不代表持续满载或所有设备的性能。

使用 Phong 材质、缓存贴地阴影，粒子与拖尾采用 InstancedMesh。Chrome 测试默认使用原生 GPU；`SOFTWARE_WEBGL=1` 可改用 SwiftShader，软件光栅化结果不能当作手机 GPU 表现。Three.js 模块经 esbuild 压缩后本地托管，开发服务器启用 gzip，静态部署也建议启用 gzip / Brotli。

仍需设备验收：Safari 应用、Android Chrome 真机 ≥45fps、移动浏览器安装入口和振动、不同音频设备，以及中端笔记本的系统 CPU 指标。PWA 安装需要 HTTPS / localhost，不能在普通局域网 HTTP 地址上验证。
